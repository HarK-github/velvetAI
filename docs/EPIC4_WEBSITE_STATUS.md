## 2. Status Terminology Summary

- **WORKING_REAL_E2E**: Verified end-to-end with real browser and local services.
- **WORKING_AUTOMATED_ONLY**: Backed by passing automated test suites; end-to-end browser UI not yet built or manual flow not yet fully exercised in browser.
- **UI_ONLY**: Client-side interactive mock/simulation for presentation purposes.
- **BLOCKED / NOT_RUN**: External provider or environment dependency unverified or untracked.
- **DEFERRED**: Explicitly scheduled for Epic 5 or post-hackathon (Bryntum Scheduler, multi-party onboarding, live PayPal).
